# Проверка алерта в кластере: 12 ноября 2026 года

На узле `node2` временные точечные правила firewall блокировали TCP-соединения к Uploader на порту 8000 только от Pod Traefik и Prometheus. Контейнер Uploader намеренно не останавливался: проверялся сетевой отказ.

При блокировке запрос через gateway вернул HTTP 502, цель метрик Uploader стала недоступна (`down`), а штатное правило `AppServiceDown` перешло в состояние `firing`. После удаления временных правил gateway снова вернул ожидаемый HTTP 401 для запроса без действительных учётных данных, цель метрик стала `up`, а алерт снялся.

Перед проверкой выполнен dry-run на безопасных адресах TEST-NET: удаление пробных правил проверено при SIGTERM и SIGKILL с двумя независимыми таймерами восстановления. После испытания временных правил и таймеров не осталось. Проверка не подтверждает поведение при остановке контейнера Uploader или всей VM.

Сценарий и условия повторного запуска приведены в [инструкции](../../monitoring/tests/live-alert/README.md).
