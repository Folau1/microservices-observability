# Проверка API под небольшой нагрузкой

Сценарий k6 проверяет, что Security и Uploader отклоняют заведомо недействительный токен со статусом 401. Существующие файлы не читаются и не изменяются; запросы создают записи в логах и метрики. Вход с действующей учётной записью и масштабирование HPA этим сценарием не проверяются.

Нагрузка ограничена одним пользователем и 20 итерациями: не более 40 внешних запросов, с паузой 2 секунды и общим лимитом 90 секунд. Отклонение от ожидаемого статуса или ошибка запроса прерывает тест при следующей оценке порогов. Порог p95 менее 1000 мс — диагностический ориентир, а не обещание SLO.

Перед запуском проверьте адрес в `low-load.js` и состояние сервисов, память, swap, место и дисковую нагрузку. При ухудшении состояния остановите тест сочетанием Ctrl+C. Для запуска из корня репозитория потребуется [k6](https://grafana.com/docs/k6/latest/set-up/install-k6/):

```bash
k6 inspect tests/load/low-load.js
k6 run tests/load/low-load.js
```

`inspect` проверяет загрузку сценария и настройки, не отправляя запросы. Увеличивать нагрузку для проверки HPA следует отдельно, с наблюдением реплик и возможностью остановки.
